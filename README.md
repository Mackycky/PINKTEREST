# 🎀 PINKterest

¡Bienvenidos a PINKterest! 💗

PINKterest es una pequeña galería de imágenes inspirada en Pinterest, pero con una temática muy particular: ¡todo es rosa! 🌸

Este proyecto consiste en una colección de imágenes organizadas en una galería visual, buscando recrear un poco el estilo y la estética de Pinterest.

### ✨ Sobre el proyecto

Este es un proyecto personal que realicé como parte de mi proceso de aprendizaje en programación. Todavía estoy aprendiendo y practicando, por lo que me apoyo en tutoriales y videos para incorporar nuevos conocimientos y llevarlos a la práctica.

Para desarrollar esta galería tomé como referencia el siguiente tutorial:

🎥 [Video tutorial de YouTube](https://youtu.be/LnEimHQRfFQ?si=9dLXv21dky8Abyw2)

Seguir practicando, aprender nuevas herramientas y mejorar mis habilidades en desarrollo web mientras creo proyectos propios.
